💧 MuftWater

MuftWater is a web-based platform that uses free drinking water containers as advertising space.
Brands promote their ads on water containers placed in public locations while people get free clean water.

🎯 Goal

To combine public service (free water) with offline advertising using a digital management system.

🛠 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL


⚙ How It Works

Brands submit advertisements

Ads are designed using Canva

Ads are printed and placed on water containers

Containers are distributed in public areas

Website manages ads, locations, and campaigns

📦 Features

Display campaign information

Manage advertisements (admin)

Store advertiser data

Promote free drinking water

Offline + online marketing model

🖥 Setup

Install XAMPP

Place project in htdocs/muftwater

Create MySQL database muftwater

Import SQL file
